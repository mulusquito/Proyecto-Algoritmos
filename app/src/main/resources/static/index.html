Acerca del proyecto

Esta aplicación implementa, desde cero (sin funciones de alto nivel de similitud/clustering), los algoritmos exigidos por el proyecto de curso "Análisis de algoritmos en el contexto de la bibliometría":

  • Requerimiento 1: Levenshtein, Needleman-Wunsch, Similitud del Coseno (TF-IDF) y Coeficiente de Jaccard (algoritmos clásicos); dos enfoques de embeddings preentrenados, GloVe 100d y FastText 300d, cada uno comparado con similitud del coseno y distancia euclidiana (algoritmos de IA).
  • Requerimiento 2: Clustering jerárquico aglomerativo con enlace simple, completo y promedio (UPGMA), evaluado con el Coeficiente de Correlación Cofenética.
  • Requerimiento 3: búsqueda de patrones con Knuth-Morris-Pratt, Boyer-Moore (caracter malo y sufijo bueno) y Rabin-Karp (rolling hash), con medición separada de los tiempos de preprocesamiento y de búsqueda.
  • Seguimiento: ranking de los términos más frecuentes del corpus con Counting Sort, Radix Sort y Bucket Sort, con medición de tiempos en milisegundos.

El backend es una aplicación Java (JDK 17+) sin dependencias externas: usa com.sun.net.httpserver para la API REST y un parser/escritor JSON propio. El uso de herramientas de IA generativa como apoyo al desarrollo se declara explícitamente en el documento técnico del repositorio (carpeta docs/).

Repositorio: rama develop para el desarrollo, rama main para el despliegue.
